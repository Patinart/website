ネットニュースの自動収集＆要約システムを構築した話


皆さんはネットニュースを見ている時にこう思った事はありませんか？

いらない情報が多すぎる……

時間はかかるし、脳の負荷もかかるし、嫌になりますよね。
そういった悩みを解決するために、無料＆ノンコードでできるシステムを構築しました。


↑最終イメージはこんな感じです（Notion）

結果として朝の10分で特定のネットニュース記事を読めるようになり、大幅な効率化を実現しています。

ざっくりとした仕組みの説明

// 使用技術・ツール
１．Make.com（iPaaS）
２．OpenAI API
３．Notion API
４．Googleアラート
５．RSS
６．HTTP
↑全て無料で使用できるツールです。
// システムの仕組み
１．Googleアラートでニュース記事を取捨選択
２．RSSで最新情報取得
３．OpenAI APIでURL抜き出し
４．HTTPで通信
５．OpenAI APIで3行要約＆重要度判定
６．Notion APIで収集＆蓄積
↑こういった構造です。
自動化プラットフォームで色々連携させているわけですね。APIが便利すぎる。無限の可能性を感じます。
↑MAKEのシナリオはこんな感じです。ネットニュース自動収取＆要約システムというと複雑そうですが、こう見ると意外とシンプルですね。
一番試行錯誤したのはプロンプト指示文です。あまり重要度が高くない記事を集められても困ってしまいます。ある程度はGoogleアラートのマイナス検索で弾けますが。
そこで私が実際にしたプロンプト指示文を貼っておきます。
// プロンプト指示文
あなたは「長期・分散の投資学習」向けニュース編集者です。
{{3.data}}を読んで①②③を実行してください。最後に提示するフォーマットに従って出力してください。
①重要度を「高いor標準or低い」で判定してください。以下を目安にしてください。
高い - 80-100: 金利/物価/景気の転換、重要政策、供給網・エネルギーの大きな変化
標準 - 50-79 : 継続観測に価値、複数国に波及、構造的テーマ
低い - 0-49 : 個人の意見、煽り、まとめ、投資勧誘、短期売買向け
②内容を150文字で箇条書きで三つで要約してください。
③根拠を因果が分かるように400文字で要約してください。専門用語は初心者にもわかるように単語の後に（）で注釈を入れてください。
以上の①②③を以下のフォーマットに当てはめて出力してください。①②③の文字は消してください。無駄なく端的な文章にしてください。

重要度：①
-②
-②
-②

【根拠】③
プロンプトはこんな内容です。実行順を分かりやすく明記することで、出力がスムーズになっていると思います。
また、Notionのフィルター機能を使えば、重要度が高い記事のみを表示させることが出来ます。これはかなり便利ですね。

以上がネットニュースの自動収集＆要約システムを構築した話でした。次もまたなにか日常の困りごとがあったら自動化システムを作ってみたいと思います。
