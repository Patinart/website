歯車の回転と当たり判定

今日はステージギミックの核となる「回転する歯車」の実装を行いました。

単純に回転させるだけなら簡単ですが、プレイヤーが乗ったときに一緒に回転させたり、挟まれたときの処理を入れるとなると、少し複雑になります。

物理演算の問題

最初はUnityの物理演算（Rigidbody）のみで制御しようとしましたが、プレイヤーが滑り落ちてしまう問題が発生しました。解決策として、プレイヤーが歯車に乗っている間だけ、親オブジェクトを歯車にする処理を追加しました。

// 擬似コードの例
if (isGrounded && target.tag == "Gear") {
  this.transform.parent = target.transform;
}

これで安定して乗れるようになりました。次は背景の描画周りを強化して、もっとパティナ（緑青）っぽさを出していきたいと思います。
